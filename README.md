CloudSentinel 🛡️

A Terraform Security Scanner & Automated Remediation Simulator

CloudSentinel is a beginner-friendly DevSecOps portfolio project designed to demonstrate how cloud infrastructure misconfigurations can be detected, prevented, and safely remediated.

🎯 Project Goals

- Identify insecure infrastructure configurations using Checkov.
- Demonstrate secure infrastructure practices with Terraform.
- Automate security checks using GitHub Actions.
- Simulate remediation of security findings using Python.
- Provide clear reports and tests demonstrating security improvements.

🏗️ Planned Architecture

1. Infrastructure as Code: Terraform security examples.
2. Security Analysis: Checkov configuration scanning.
3. CI/CD Security: GitHub Actions automated validation.
4. Remediation Simulator: Python-based demonstration of proposed fixes.
5. Testing & Reporting: Automated tests and documented scan results.

🔒 Security and Cost

- Designed to run locally and through GitHub Actions without deploying paid cloud infrastructure.
- No AWS credentials are required for the initial version.
- Remediation is simulated; it does not modify live cloud resources.
- Security findings and test results will be documented as the project develops.
